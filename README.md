# 制作物・創作活動についての紹介
### 川崎龍稀

自作の物語をゲームとして表現するために、個人でゲーム制作に挑戦しています。そしてこのページでは、制作物としてのアピールポイントとして、現在制作しているRPGとその制作の基礎となったロボット操縦シミュレーターについて紹介します。

## <1.自作RPG/現在取り組んでいる制作>

幼い頃に作っていた絵本を基に、中学、高校と時間を経て創作を重ねてきた物語をRPGにするという挑戦プロジェクトです。

[自作RPGへの紹介へ](rpg.md)

## <2.ロボット操縦シミュレーター/過去に行ったゲーム制作>

UnityやBlenderを独学で学び、よりリアルな操作を求めて試行錯誤をした最初のゲーム制作です。

[ロボットシミュレーターの紹介へ](robotsim.md)

各制作物はスライドを中心に紹介し、補足を文章で記載しています。1ではRPG制作の背景や現在の取組みを、2ではその基礎となったロボットシミュレーターでの挑戦や、制作を通じて得た経験を中心として紹介しています。

# 生成AIツールの使用について

ゲームに制作および本紹介ページの作成では、ChatGPTを以下の目的で使用しています。

・UnityやBlenderの基本設定・操作方法の確認  
・C#の基礎学習、スクリプト作成の補助（ベースコードの作成を含みます）  
・挙動改善のための計算式作成の補助  
・エラーやバグの原因特定の補助  
・GitHubの操作方法やリンク、画像の掲載方法の確認  

#### ゲーム制作における設計思想やアイデア、モデル作成、各機能の調整、設計は自身で行っています。
##### 主に、2で紹介するロボットシミュレーターの制作初期での、何から始め、どのような手順で制作に挑戦すれば良いのかわからないことが多かった、というところで必要な知識や手順を確認するために活用しました。
各制作物における具体的な使用箇所は、それぞれの紹介ページにて記載しております。
